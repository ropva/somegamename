# somegamename
A resource management game where you have to balance resources and expand your colony across the solar system

## Features
- Dynamically generated planets
    - Each planet has generated resources and energy potentials
    - Planet color is generated from the resource distribution
- Configurable building system
    - Adding new buildings is very easy
- Science system (WIP)

## Godot configuration
- All scripts in /scrips/
- All scenes in /scenes/
- All assets in /res/
