# Skill Tree Editor

Universal Godot 4 skill-tree editor, runtime UI, progression and local save system.

## Documentation

- [English user guide](docs/USER_GUIDE_EN.md)
- [Руководство пользователя на русском](docs/USER_GUIDE_RU.md)
- [AGENTS.md](AGENTS.md) — instructions for Codex and other coding agents adapting the addon

Copy the whole `addons/skill_tree_editor` directory into a project and enable **Skill Tree** in **Project > Project Settings > Plugins**. The addon registers one autoload only: `SkillTree`.
