# Skill Tree Editor — руководство пользователя

Здесь описан полный путь: установка аддона, создание дерева, настройка валют и эффектов, подключение UI и использование данных навыков в игре.

## 1. Установка

1. Скопируйте всю папку `addons/skill_tree_editor` в папку `addons` целевого Godot-проекта.
2. Откройте проект в Godot 4.0 или новее. Аддон проверен на Godot 4.8.
3. Включите **Skill Tree**: **Project > Project Settings > Plugins**.
4. Проверьте, что Godot добавил ровно один autoload — `SkillTree`.

Не добавляйте `SkillTreeStorage` и `SkillProgression` вручную: это внутренние сервисы `SkillTree`.

## 2. Создание ресурса дерева

1. Откройте вкладку **Skill Tree** в главном экране редактора.
2. Нажмите **Новый**. Будут созданы валюта `skillpoints` и первый корневой навык.
3. Настройте дерево и сохраните `.tres` вне папки аддона — например, в `res://res/skill_trees/player_tree.tres`.
4. Позже используйте **Открыть**, чтобы продолжить редактирование, и обычное **Сохранить**, чтобы безопасно перезаписать ресурс.

Origin дерева — мировая точка `(0, 0)`. Первый навык имеет позицию верхнего левого угла `(-192, -192)`: карточка размером 384×384 находится центром в origin. Команда **Центр/Origin** располагает точку `(0, 0)` в центре viewport редактора.

## 3. Языки и категории

В панели **Языки** добавляйте и удаляйте локали дерева. По умолчанию существуют русский и английский. Интерфейс аддона переводится автоматически; ваши названия, описания, категории, валюты и характеристики вы вводите для нужных языков сами.

В панели **Категории** создавайте категории навыков. Они хранятся в конкретном `.tres` дерева и не зашиты в аддон.

## 4. Валюты

Откройте кнопку **Валюты** на верхней панели.

У каждой валюты есть:

- постоянный ключ строчными латинскими буквами, например `skillpoints`, `gold`, `research_token`;
- полное название и сокращение для каждого языка дерева;
- необязательная иконка;
- стартовое количество для нового сохранения.

Ключ после создания не меняется, потому что на него ссылаются навыки и сохранения. В дереве всегда должна оставаться хотя бы одна валюта. При удалении используемой валюты её навыки переводятся на первую оставшуюся.

В игре цена отображается с иконкой валюты, если она задана; иначе показывается локализованное сокращение. Цена `0` всегда отображается как `FREE`.

## 5. Характеристики и эффекты

В редакторе характеристик создайте значения, которые будут меняться от навыков. Для характеристики задаются:

- постоянный ключ, например `carry_capacity`;
- тип: Int, Float, Bool, Array или Dictionary;
- базовое значение для нового сохранения;
- локализованное название и при необходимости переводы элементов коллекций.

В эффектах навыка выберите ключ характеристики и операцию. Для чисел доступны add, subtract, multiply, divide и set. Ограничение min/max применяется только при включённом toggle. `ADD_UNIQUE` предназначен для Dictionary. Некорректные операции и деление на ноль не проходят проверку.

Чтобы уже прокачанный до максимума навык работал как переключатель, добавьте Bool-эффект `SET` и включите `toggle_mode`: в details-панели появится Enable/Disable.

## 6. Настройка навыков и связей

ПКМ по пустому месту графа создаёт навык. В превью карточки настраиваются:

- название, описание, категория и иконка;
- максимальный уровень;
- валюта, базовая цена, рост цены или ручные цены уровней;
- **Виден сразу**;
- требования и эффекты.

Toggle **Виден сразу** отвечает только за видимость. Навык без требований можно прокачивать сразу. Требования отвечают за состояние «Заблокировано». Протяните порт выхода родительского навыка на порт входа дочернего, чтобы создать связь-требование. Валидатор проверяет ID, отсутствующие ссылки, циклы, валюты и совместимость эффектов.

Команда ПКМ **Переместить в центр** ставит карточку на `(-192, -192)`.

## 7. Подключение дерева к сцене игры

1. Добавьте `res://addons/skill_tree_editor/scenes/skill_tree_view.tscn` в свой UI `Control` или `CanvasLayer`.
2. Назначьте сохранённый `SkillTreeData` в поле `skill_tree_data`.
3. Укажите `save_slot`: обычно `default` или ID профиля.
4. Выберите режим `DIRECT_PURCHASE` или `DETAILS_PANEL`.
5. Из своего UI вызывайте `open()` и `close()`.

`SkillTreeView` сам конфигурирует активное дерево при готовности. В нём уже есть pan, zoom колесом мыши, перемещение WASD/стрелками, линии связей, карточки и details-панель. Сцены интерфейса редактируемы: можно создать свои и назначить их через export-поля `SkillTreeView`.

## 8. Использование данных в игровом коде

Единственная поддерживаемая точка доступа — autoload `SkillTree`.

```gdscript
# Выдать награду.
SkillTree.add_currency("skillpoints", 3)

# Прочитать значение, изменённое эффектами.
var capacity := int(SkillTree.get_value("carry_capacity", 4))

# Проверить и купить навык.
if SkillTree.prerequisites_met("sprint") and SkillTree.purchase_skill("sprint"):
	print("Куплено")

# Получить снимок для будущей интеграции облачного сохранения.
var state: Dictionary = SkillTree.export_state()
```

Основные API:

- запросы навыков: `get_level`, `get_skill_state`, `is_visible`, `prerequisites_met`, `get_missing_prerequisites`;
- действия: `purchase_skill`, `toggle_skill`, `is_toggle_skill_active`, `set_toggle_skill_active`;
- валюты: `get_currency`, `set_currency`, `add_currency`, `can_afford`, `spend_currency`;
- значения: `get_value`, `set_value`, `player_data`;
- сохранения: `export_state`, `import_state`, `clear_current_state`, `clear_state`, `clear_all_states`.

Сигналы: `configured`, `currency_changed`, `skill_purchased`, `skill_toggled`, `skill_state_changed`, `skill_purchase_failed`, `state_changed`.

## 9. Сохранения и миграция

Статическое содержимое хранится в вашем `.tres`. Runtime-состояние автоматически сохраняется после покупок и явных изменений по пути:

`user://skill_tree/<save_slot>/<tree_id>.json`

Снимок включает `version`, `tree_id`, `currencies`, `levels` и `values`. Старые сохранения версии 1 с `skill_points` один раз мигрируются в `currencies.skillpoints`. Сохранение локальное: облако, Steam/Web SDK и host-authority для мультиплеера реализуются в проекте-носителе через `export_state()`/`import_state()`.

Для очистки состояния вызывайте `SkillTree.clear_current_state()` либо другой явный clear API. Аддон не создаёт горячие клавиши очистки в проекте.

## 10. Безопасная кастомизация

В панели **Настройки** находятся Категории, Характеристики, Валюты, Языки и Цвета. Там же задаётся процент возврата для игрового сброса; для нового дерева по умолчанию используется 50%.

В runtime балансы валют отображаются в VBox в левом нижнем углу. Кнопка сброса находится справа сверху. Она открывает подтверждение и возвращает заданный процент от точно записанных трат на навыки. `Ctrl+R` — только debug-сброс через `reset_skilltree_data`: он очищает сохранение активного дерева без возврата.

Без изменения логики можно назначить свои:

- сцену `SkillNode`;
- сцену линий `Line2D`;
- details-панель;
- иконки, шрифты и тему;
- цвета, валюты, характеристики и локали в `SkillTreeData`.

При изменении встроенных сцен сохраняйте нужные именованные узлы и скрипты. Для изменений кода сначала прочитайте `../AGENTS.md`: там описаны варианты переносимости и совместимости сохранений.

## Решение проблем

| Проблема | Что проверить |
| --- | --- |
| Нет `SkillTree` | Включён ли плагин, и нет ли чужого autoload с именем `SkillTree`. |
| Навык не покупается | Требования, баланс нужной валюты, максимальный уровень и корректность эффектов. |
| Навык скрыт | Включите «Виден сразу» или прокачайте хотя бы одного родителя требования. |
| Вместо цены выводится ключ | Заполните полное название/сокращение валюты для текущей локали. |
| Изменения не сохраняются | Сохраните `.tres` и проверьте `user://skill_tree/<slot>/<tree_id>.json`. |
